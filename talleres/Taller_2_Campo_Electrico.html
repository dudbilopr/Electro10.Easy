Formulario Maestro de Referencia

Torque y Energía \[\vec{\tau} = \vec{p}\times\vec{E}, \quad U = -\vec{p}\cdot\vec{E}\]

Problema 1: Campo Resultante en el Vértice Libre de un Cuadrado

Nivel Intermedio

Tres cargas puntuales están situadas en los vértices de un cuadrado de lado $L = 0{,}30\ \text{m}$ en el plano $xy$: $q_1 = +5{,}0\ \text{nC}$ en $(0, L)$, $q_2 = -5{,}0\ \text{nC}$ en $(0, 0)$ y $q_3 = +5{,}0\ \text{nC}$ en $(L, 0)$. Determina analíticamente el vector campo eléctrico resultante $\vec{E}_{\text{net}}$ en el vértice desocupado $P(L, L)$.

1Identificación de Fuentes y Vectores de Posición:

Fuentes: $q_1 = +5\ \text{nC}$ en $(0, 0{,}30)$, $q_2 = -5\ \text{nC}$ en $(0, 0)$, $q_3 = +5\ \text{nC}$ en $(0{,}30, 0)$.
Punto de campo: $P(0{,}30, 0{,}30)\ \text{m}$.

2Esquema Vectorial y Distancias:

De $q_1$ a $P$: vector relativo $\vec{r}_{1P} = 0{,}30\hat{\imath} + 0\hat{\jmath}$, distancia $r_1 = L = 0{,}30\ \text{m}$.
De $q_3$ a $P$: vector relativo $\vec{r}_{3P} = 0\hat{\imath} + 0{,}30\hat{\jmath}$, distancia $r_3 = L = 0{,}30\ \text{m}$.
De $q_2$ a $P$: vector diagonal $\vec{r}_{2P} = 0{,}30\hat{\imath} + 0{,}30\hat{\jmath}$, distancia $r_2 = L\sqrt{2} = 0{,}30\sqrt{2} \approx 0{,}424\ \text{m}$.

3Magnitudes de Campo Individuales ($k_e = 8{,}99\times 10^9\ \text{N}\cdot\text{m}^2/\text{C}^2$): \[E_1 = k_e \frac{|q_1|}{L^2} = (8{,}99\times 10^9)\frac{5\times 10^{-9}}{(0{,}30)^2} = \frac{44{,}95}{0{,}09} = 499{,}4\ \text{N/C}\] \[E_3 = k_e \frac{|q_3|}{L^2} = 499{,}4\ \text{N/C}\] \[E_2 = k_e \frac{|q_2|}{(L\sqrt{2})^2} = \frac{k_e |q_2|}{2L^2} = \frac{499{,}4}{2} = 249{,}7\ \text{N/C}\]
4Orientaciones y Descomposición Vectorial:

$q_1 > 0 \implies \vec{E}_1$ sale de $q_1$ hacia la derecha: $\vec{E}_1 = +499{,}4\hat{\imath}\ \text{N/C}$.
$q_3 > 0 \implies \vec{E}_3$ sale de $q_3$ hacia arriba: $\vec{E}_3 = +499{,}4\hat{\jmath}\ \text{N/C}$.
$q_2 < 0 \implies \vec{E}_2$ entra hacia $q_2$ a lo largo de la diagonal a $225^\circ$: $\cos(225^\circ) = -\frac{\sqrt{2}}{2}$, $\sin(225^\circ) = -\frac{\sqrt{2}}{2}$.

5 Resolución por Dos Caminos Analíticos:

Camino A: Suma directa de proyecciones angulares.

\[E_{2x} = -E_2 \frac{\sqrt{2}}{2} = -(249{,}7)(0{,}7071) = -176{,}6\ \text{N/C}\] \[E_{2y} = -E_2 \frac{\sqrt{2}}{2} = -(249{,}7)(0{,}7071) = -176{,}6\ \text{N/C}\] \[E_{\text{net},x} = E_{1x} + E_{2x} = 499{,}4 - 176{,}6 = +322{,}8\ \text{N/C}\] \[E_{\text{net},y} = E_{3y} + E_{2y} = 499{,}4 - 176{,}6 = +322{,}8\ \text{N/C}\]

Camino B: Notación vectorial cúbica con vectores de posición relativos.

\[\vec{E}_2 = \frac{q_2}{4\pi\epsilon_0}\frac{\vec{r}_P - \vec{r}_2}{|\vec{r}_P - \vec{r}_2|^3} = (8{,}99\times 10^9)\frac{(-5\times 10^{-9})}{(0{,}30\sqrt{2})^3}(0{,}30\hat{\imath} + 0{,}30\hat{\jmath})\] Como $(0{,}30\sqrt{2})^3 = 0{,}027 \times 2\sqrt{2} = 0{,}07637\ \text{m}^3$: \[\vec{E}_2 = \frac{-44{,}95}{0{,}07637}(0{,}30\hat{\imath} + 0{,}30\hat{\jmath}) = -176{,}6\hat{\imath} - 176{,}6\hat{\jmath}\ \text{N/C}\] Sumando $\vec{E}_1 = 499{,}4\hat{\imath}$ y $\vec{E}_3 = 499{,}4\hat{\jmath}$: $\vec{E}_{\text{net}} = 322{,}8\hat{\imath} + 322{,}8\hat{\jmath}\ \text{N/C}$.
6Magnitud y Dirección Resultante: \[|\vec{E}_{\text{net}}| = \sqrt{(322{,}8)^2 + (322{,}8)^2} = 322{,}8\sqrt{2} \approx 456{,}5\ \text{N/C}\] \[\theta = \arctan\left(\frac{322{,}8}{322{,}8}\right) = \arctan(1) = 45{,}0^\circ\]
7Resultado Final Verificado: El campo eléctrico en el vértice $P$ es $\vec{E}_{\text{net}} = (323\hat{\imath} + 323\hat{\jmath})\ \text{N/C}$, con magnitud de $457\ \text{N/C}$ apuntando exactamente a $45^\circ$ sobre la diagonal hacia el primer cuadrante.

Problema 2: Dinámica de un Dipolo Eléctrico en Campo Externo

Nivel Avanzado

Un dipolo eléctrico está formado por cargas de $+3{,}0\ \text{nC}$ y $-3{,}0\ \text{nC}$ separadas por $d = 4{,}0\ \text{mm}$, con momento de inercia $I = 2{,}5\times 10^{-9}\ \text{kg}\cdot\text{m}^2$. Se encuentra sumergido en un campo uniforme $E_0 = 5{,}0\times 10^4\ \text{N/C}$.
(a) Calcula el momento dipolar $\vec{p}$ y el torque máximo $\tau_{\max}$.
(b) Determina la frecuencia angular $\omega$ de pequeñas oscilaciones armónicas cuando se perturba un ángulo pequeño $\theta \ll 1$.

Momento Dipolar y Torque Pico: \[p = q d = (3{,}0\times 10^{-9}\ \text{C})(4{,}0\times 10^{-3}\ \text{m}) = 1{,}20\times 10^{-11}\ \text{C}\cdot\text{m}\] \[\tau_{\max} = p E_0 = (1{,}20\times 10^{-11})(5{,}0\times 10^4) = 6{,}00\times 10^{-7}\ \text{N}\cdot\text{m}\]
Ecuación Diferencial del Oscilador Armónico: Aplicando la 2.ª ley de Newton para rotación: $\sum \tau = I \alpha \implies -p E_0 \sin\theta = I \frac{d^2\theta}{dt^2}$.
Para ángulos pequeños, $\sin\theta \approx \theta$: \[\frac{d^2\theta}{dt^2} + \left(\frac{p E_0}{I}\right)\theta = 0 \implies \omega = \sqrt{\frac{p E_0}{I}} = \sqrt{\frac{6{,}00\times 10^{-7}}{2{,}5\times 10^{-9}}} = \sqrt{240} \approx 15{,}49\ \text{rad/s}\] Frecuencia cíclica: $f = \frac{\omega}{2\pi} = \frac{15{,}49}{6{,}283} \approx 2{,}47\ \text{Hz}$.
