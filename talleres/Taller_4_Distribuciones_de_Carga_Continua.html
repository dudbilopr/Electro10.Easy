Formulario Maestro de Integración Continua

Diferencial de Campo Integral \[d\vec{E} = \frac{1}{4\pi\epsilon_0}\frac{dq}{\mathcal{R}^2}\hat{\mathcal{R}}\]
Hilo Finito (Mediatriz) \[E_y = \frac{2k\lambda L}{y\sqrt{4y^2 + L^2}}\]
Anillo Circular (Eje Axial) \[E_x = \frac{k Q x}{(x^2 + R^2)^{3/2}}\]
Límite Hilo Infinito \[E = \frac{\lambda}{2\pi\epsilon_0 r}\]

Problema 1: Campo Eléctrico en la Mediatriz de un Segmento Recto

Nivel Intermedio

Una varilla delgada y no conductora de longitud $L = 0{,}60\ \text{m}$ descansa sobre el eje $x$ centrada en el origen (extendiéndose desde $x = -0{,}30\ \text{m}$ hasta $x = +0{,}30\ \text{m}$). La varilla posee una carga total uniforme $Q = +15{,}0\ \text{nC}$. Determina la magnitud y dirección del vector de campo eléctrico $\vec{E}$ en un punto $P(0, 0{,}20\ \text{m})$ sobre el eje $y$.

1 Identificación y Parametrización Geométrica de la Distribución:

Longitud $L = 0{,}60\ \text{m}$, carga $Q = 15{,}0\times 10^{-9}\ \text{C}$.
Densidad lineal uniforme: $\lambda = \frac{Q}{L} = \frac{15{,}0\times 10^{-9}\ \text{C}}{0{,}60\ \text{m}} = 25{,}0\times 10^{-9}\ \text{C/m} = 25{,}0\ \text{nC/m}$.
Elemento diferencial de carga ubicado en una coordenada fuente $x'$: $dq = \lambda dx'$.

2 Vector de Posición Relativa y Distancia Euclídea:

Punto fuente: $\vec{r}' = x'\hat{\imath} + 0\hat{\jmath}$. Punto de campo: $\vec{r} = 0\hat{\imath} + y\hat{\jmath}$ (donde $y = 0{,}20\ \text{m}$).
Vector de separación relativa: $\vec{\mathcal{R}} = \vec{r} - \vec{r}' = -x'\hat{\imath} + y\hat{\jmath}$.
Distancia euclídea al elemento: $\mathcal{R} = \sqrt{(-x')^2 + y^2} = \sqrt{x'^2 + y^2}$.

3 Diferencial Vectorial de Campo $d\vec{E}$ y Descomposición:
\[d\vec{E} = \frac{1}{4\pi\epsilon_0}\frac{dq}{\mathcal{R}^3}\vec{\mathcal{R}} = \frac{k\lambda dx'}{(x'^2 + y^2)^{3/2}}(-x'\hat{\imath} + y\hat{\jmath})\] \[dE_x = -\frac{k\lambda x' dx'}{(x'^2 + y^2)^{3/2}}, \quad dE_y = \frac{k\lambda y dx'}{(x'^2 + y^2)^{3/2}}\]
4 Análisis de Simetría Especular (Cancelación de $E_x$):

El integrando de $E_x$ es una función impar respecto a $x'$ ($f(-x') = -f(x')$), mientras que el intervalo de integración $[-L/2, L/2]$ es simétrico alrededor del origen. Por simetría par/impar: \[E_x = \int_{-L/2}^{L/2} dE_x = 0\] El integrando de $E_y$ es estrictamente par ($f(-x') = f(x')$). Por ende: \[E_y = 2\int_0^{L/2} dE_y = 2 k\lambda y \int_0^{L/2}\frac{dx'}{(x'^2 + y^2)^{3/2}}\]

Paso 5: Resolución de la Integral — Elige el Camino Analítico:
Camino A (Método Clásico Angular):
Hacemos el cambio de variable angular $x' = y\tan\theta \implies dx' = y\sec^2\theta d\theta$.
El denominador se transforma: $(x'^2 + y^2)^{3/2} = (y^2(\tan^2\theta + 1))^{3/2} = (y^2\sec^2\theta)^{3/2} = y^3\sec^3\theta$.
Sustituyendo en la integral indefinida: \[\int \frac{dx'}{(x'^2 + y^2)^{3/2}} = \int \frac{y\sec^2\theta d\theta}{y^3\sec^3\theta} = \frac{1}{y^2}\int \frac{d\theta}{\sec\theta} = \frac{1}{y^2}\int \cos\theta d\theta = \frac{\sin\theta}{y^2}\] Regresando a la variable cartesiana mediante el triángulo rectángulo asociado ($\sin\theta = \frac{x'}{\sqrt{x'^2 + y^2}}$): \[\left[ \frac{x'}{y^2\sqrt{x'^2 + y^2}} \right]_0^{L/2} = \frac{L/2}{y^2\sqrt{(L/2)^2 + y^2}} = \frac{L}{y^2\sqrt{4y^2 + L^2}}\]
Camino B (Tabla de Primitivas Algebraicas):
Utilizando directamente la fórmula de integración de tablas estándar $\int \frac{du}{(u^2 + a^2)^{3/2}} = \frac{u}{a^2\sqrt{u^2 + a^2}} + C$ con $u=x'$ y $a=y$: \[\int_0^{L/2}\frac{dx'}{(x'^2 + y^2)^{3/2}} = \left[ \frac{x'}{y^2\sqrt{x'^2 + y^2}} \right]_0^{L/2} = \frac{L/2}{y^2\sqrt{(L/2)^2 + y^2}}\] Ambos caminos conducen a la misma expresión cerrada exacta.
6 Expresión Analítica Final y Validación Asintótica:
\[E_y = 2 k\lambda y \left( \frac{L/2}{y^2\sqrt{(L/2)^2 + y^2}} \right) = \frac{k\lambda L}{y\sqrt{y^2 + (L/2)^2}} = \frac{2k\lambda L}{y\sqrt{4y^2 + L^2}}\]

Comprobación de límites:
• Límite puntual ($y \gg L$): $\sqrt{4y^2+L^2} \approx 2y \implies E_y \approx \frac{2k\lambda L}{y(2y)} = \frac{k(\lambda L)}{y^2} = \frac{kQ}{y^2}$ (¡Correcto!).
• Límite alambre infinito ($L \gg y$): $\sqrt{4y^2+L^2} \approx L \implies E_y \approx \frac{2k\lambda L}{y L} = \frac{2k\lambda}{y} = \frac{\lambda}{2\pi\epsilon_0 y}$ (¡Correcto!).

7 Sustitución Numérica y Solución Vectorial Final:

Datos: $k = 8{,}99\times 10^9\ \text{N}\cdot\text{m}^2/\text{C}^2$, $\lambda = 25{,}0\times 10^{-9}\ \text{C/m}$, $L = 0{,}60\ \text{m}$, $y = 0{,}20\ \text{m}$.

\[4y^2 + L^2 = 4(0{,}20)^2 + (0{,}60)^2 = 4(0{,}04) + 0{,}36 = 0{,}16 + 0{,}36 = 0{,}52\ \text{m}^2\] \[\sqrt{4y^2 + L^2} = \sqrt{0{,}52} \approx 0{,}72111\ \text{m}\] \[E_y = \frac{2(8{,}99\times 10^9)(25{,}0\times 10^{-9})(0{,}60)}{(0{,}20)(0{,}72111)} = \frac{269{,}7}{0{,}14422} \approx 1870{,}0\ \text{N/C}\]
Vector de Campo Eléctrico Neto: \[\vec{E} = 0\hat{\imath} + 1{,}87\times 10^3\hat{\jmath}\ \text{N/C} = (1{,}87\ \text{kN/C})\hat{\jmath}\]
Calculadora Paramétrica para Problema 1:
Resultado: $E_y = 1870{,}0\ \text{N/C}$  |  $\vec{E} = 1870{,}0\hat{\jmath}\ \text{N/C}$

Problema 2: Campo Axial de un Anillo y Optimización del Máximo

Nivel Avanzado

Un anillo delgado de plástico de radio $R = 0{,}15\ \text{m}$ se encuentra fijo en el plano $yz$ centrado en el origen. El anillo tiene una carga neta positiva $Q = +30{,}0\ \text{nC}$ distribuida homogéneamente a lo largo de su perímetro.
a) Deduce analíticamente la expresión del campo eléctrico sobre el eje axial $x$ y evalúa su magnitud en $x = 0{,}20\ \text{m}$.
b) Mediante cálculo diferencial ($dE_x/dx = 0$), demuestra la coordenada $x_{\text{máx}}$ donde el campo alcanza su valor máximo absoluto y calcula dicho campo pico.

1 Definición Geométrica y Simetría Azimutal:

Radio $R = 0{,}15\ \text{m}$, carga total $Q = 30{,}0\times 10^{-9}\ \text{C}$.
Elemento de arco en el anillo: $ds = R d\phi$. Diferencial de carga: $dq = \lambda ds = \frac{Q}{2\pi R}(R d\phi) = \frac{Q}{2\pi} d\phi$.

2 Invarianza de la Distancia Euclídea:

Para cualquier punto sobre el anillo, las coordenadas son $(0, R\cos\phi, R\sin\phi)$.
La distancia euclídea al punto de observación $P(x, 0, 0)$ es estrictamente constante para todo el anillo: \[\mathcal{R} = \sqrt{(x - 0)^2 + (0 - R\cos\phi)^2 + (0 - R\sin\phi)^2} = \sqrt{x^2 + R^2(\cos^2\phi + \sin^2\phi)} = \sqrt{x^2 + R^2}\]

3 Cancelación de Componentes Perpendiculares al Eje:

Para cada elemento $dq$ ubicado en un ángulo $\phi$, existe un elemento idéntico situado en $\phi + \pi$ diametralmente opuesto. Sus componentes radiales en el plano $yz$ son iguales en módulo y con sentidos opuestos: \[\vec{E}_\perp = \int (dE_y\hat{\jmath} + dE_z\hat{k}) = \vec{0}\] Por tanto, el campo resultante es estrictamente unidireccional sobre el eje axial $x$.

4 Proyección Axial e Integración:

El ángulo $\theta$ entre el vector $\vec{\mathcal{R}}$ y el eje $x$ cumple $\cos\theta = \frac{x}{\sqrt{x^2 + R^2}}$.

\[dE_x = dE \cos\theta = \left(\frac{k\, dq}{x^2 + R^2}\right)\left(\frac{x}{\sqrt{x^2 + R^2}}\right) = \frac{k x\, dq}{(x^2 + R^2)^{3/2}}\] \[E_x = \int dE_x = \frac{k x}{(x^2 + R^2)^{3/2}}\oint_{\text{anillo}} dq = \frac{k Q x}{(x^2 + R^2)^{3/2}}\]
5 Evaluación Numérica en $x = 0{,}20\ \text{m}$:
\[x^2 + R^2 = (0{,}20)^2 + (0{,}15)^2 = 0{,}0400 + 0{,}0225 = 0{,}0625\ \text{m}^2\] \[(x^2 + R^2)^{3/2} = (0{,}0625)^{3/2} = (\sqrt{0{,}0625})^3 = (0{,}25)^3 = 0{,}015625\ \text{m}^3\] \[E_x = \frac{(8{,}99\times 10^9\ \text{N}\cdot\text{m}^2/\text{C}^2)(30{,}0\times 10^{-9}\ \text{C})(0{,}20\ \text{m})}{0{,}015625\ \text{m}^3} = \frac{53{,}94}{0{,}015625} = 3452{,}16\ \text{N/C} \approx 3{,}45\ \text{kN/C}\]
6 Demostración Analítica del Punto de Campo Máximo ($x_{\text{máx}}$):

Aplicando la regla del cociente o del producto a la función $E_x(x) = kQ \cdot x (x^2 + R^2)^{-3/2}$:

\[\frac{dE_x}{dx} = kQ \left[ 1\cdot (x^2 + R^2)^{-3/2} + x \cdot \left(-\frac{3}{2}\right)(x^2 + R^2)^{-5/2}(2x) \right] = 0\] \[(x^2 + R^2)^{-3/2} - 3x^2(x^2 + R^2)^{-5/2} = 0\]

Multiplicando ambos lados por $(x^2 + R^2)^{5/2}$:

\[(x^2 + R^2) - 3x^2 = 0 \implies R^2 - 2x^2 = 0 \implies x^2 = \frac{R^2}{2}\]
Coordenada del Máximo Axial: \[x_{\text{máx}} = \frac{R}{\sqrt{2}} = \frac{0{,}15\ \text{m}}{\sqrt{2}} \approx 0{,}10607\ \text{m} = 10{,}61\ \text{cm}\]
7 Cálculo del Campo Máximo Pico ($E_{\text{máx}}$):
\[x_{\text{máx}}^2 + R^2 = \frac{R^2}{2} + R^2 = \frac{3}{2}R^2\] \[(x_{\text{máx}}^2 + R^2)^{3/2} = \left(\frac{3}{2}\right)^{3/2} R^3 = \frac{3\sqrt{3}}{2\sqrt{2}} R^3\] \[E_{\text{máx}} = \frac{k Q (R/\sqrt{2})}{(3\sqrt{3} / 2\sqrt{2}) R^3} = \frac{2 k Q}{3\sqrt{3} R^2} = \frac{2(8{,}99\times 10^9)(30{,}0\times 10^{-9})}{3\sqrt{3}(0{,}15)^2} = \frac{539{,}4}{3(1{,}73205)(0{,}0225)} = \frac{539{,}4}{0{,}11691} \approx 4613{,}7\ \text{N/C}\]
Conclusión del Problema 2: \[E_x(0{,}20\ \text{m}) = 3{,}45\times 10^3\hat{\imath}\ \text{N/C}, \quad x_{\text{máx}} = 10{,}61\ \text{cm}, \quad E_{\text{máx}} = 4{,}61\times 10^3\ \text{N/C}\]
